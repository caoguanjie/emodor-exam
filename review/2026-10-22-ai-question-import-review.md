# AI 参考题导入独立评审与修复记录

## 范围

- 试题管理 / 试卷管理 / 试题导入 / 考试记录菜单拆分。
- 试题导入页“文件导入 / AI 生成”双 Tab。
- 一次性参考题 easy/hard 生成、预览、修改、单题重生成、导出与 pending 确认。
- 参考文件/正文零留存、owner/kind/权限隔离、事务幂等与异步结果未知处理。

## 独立评审发现与修复

1. **高风险：供应商非 JSON / 传输异常可将参考正文带入日志**
   - 修复：`AiGatewayService` 只保留固定失败分类，HTTP 错误正文不读取，不记录供应商异常 message。
   - 回归：新增 `ai-gateway-privacy.spec.ts`，使用原生 `Response.json()` 和 `REFERENCE_CANARY` 覆盖非 JSON、网络异常、401/429/503 及两类连通性测试。

2. **高风险：模型可回放同批其他参考题到生成批次**
   - 修复：任务运行期在内存中建立整批参考片段和完整短选项集指纹，预览写入前拒绝题干、解析或选项回放；任务结束清空集合。判断题固定“正确/错误”豁免，避免误杀。
   - 回归：覆盖跨参考题干、解析、长选项、短选项集回放，以及短通用词不误杀。

3. **中风险：页面失活后预览 busy 状态可永久锁死**
   - 修复：`deactivate()` 取消当前代次并清理可失效读状态；已发出但结果不确定的写入仍保留锁定。重新激活后可重新上传或查询原任务。
   - 回归：覆盖普通预览、AI 完成后批次读取、确认写入三个失活窗口。

4. **中风险：生成行修改/重生成已落服务端但回包丢失时，界面可按旧内容确认**
   - 修复：不可确认的行写入进入锁定对账态，禁止修改、重生成和确认导入；只能 GET 同一批次收敛，界面重新展示服务端题面后再操作。
   - 回归：覆盖修改、重生成、无法验证响应、明确 4xx、对账再次中断和弹窗内对账。

5. **低风险：非数组 `options/answer` PATCH 返回 500**
   - 修复：服务端显式验证数组类型，统一返回 40001。

6. **条件风险：reduced-motion 下遮罩可退化为全屏 fixed**
   - 修复：`.page-enter` 显式 `position:relative`，内容遮罩显式 `position:absolute; inset:-16px`，不再依赖入场动画的 transform 建立包含块。
