# 课程目录与学习状态对齐

日期：2026-10-28。用户批准课时右侧显示学习百分比，播放时及时反馈“正在学习”，列表按 Pencil 设计实施。

## 设计与行为

已通过 Pencil MCP 重新读取 `docs/ui/pen-gemini.pen` 的 `esQcE`、`t6Z5eu`、`B4ZpOc`。目录采用章节白色圆角卡片，左右留白 16px、上下及章间 12px，章头与普通课时行 48px，选中课时行 64px。复用 Wot UI 2.3.2 collapse，通过公开 custom-style 配置，未修改组件库或 .pen 文件。

- 选中课时用浅蓝底与播放图标；是否完成独立显示绿色标签，不再将所有完成课时都当作当前选中。
- 明确零进度显示 `0%`，已有覆盖显示“已学 25%”。百分比只取后端 `coverage_ms / duration_ms`，向下取整，未完成最多 99%；完成仅服从 `completed`。缺失或版本不符的记录保留“视频”，不伪造学习数据。
- 播放器实际触发 play 后立即在当前课时标题下显示“正在学习”，无需等待第一拍心跳回包；暂停、缓冲、切后台、错误或切课后随既有状态机清除。百分比不使用本地播放时间，不修改心跳或计时协议。
- 章节折叠只随目录结构/预设折叠配置初始化，不再被每次进度更新重置。静态播放器和详情预览同步选中状态。
- 学员文案改为“学习进度会自动保存，请保持页面打开并正常播放”。

## 发现的既有小程序编译阻断

微信工具报 `pages/profile/terms.wxss (1:1056) error at token '*'`。定位为服务协议页已有 `.rich-node--heading + *` 选择器；改成 RichNode 实际输出的显式类组合，保持标题后间距语义，重新编译后微信工具成功载入。服务协议 H5 加载重试与富文本排版回归 2 项通过。

本次没有数据库、后端计时、鉴权、学习完成门槛或真实学习数据写入改动；没有提交或发布。
