## 已实现与复核

- 用户、assignment、记录、试卷按确定顺序加锁；记录、题单和题图引用同事务提交。真实 20 并发开考仅产生一份活动答卷，不依赖 Redis start 锁正确性。
- 首次冻结来源、类别、难度、发布版本与规则；每次持久化题面、分值、顺序和选项映射。第三次活动答卷仍可恢复，旧记录计入次数，补考不重新计算归属。
- 新 `/me` 接口以字符串 item ID 作答；旧固定接口保留 source question ID 和原响应结构。两种编号严格映射，不以数值相同推断身份。
- 在考只返回安全题面字段；本人只能读取冻结题干/选项中的题图，不开放标准答案、解析或 rubric 图片。
- 独立审查发现并修复两项旧接口回归：动态题库预检误挡冻结入口；终态 GET 恢复丢失 `finished:true` 成绩摘要。有效 active、release 和补考都只依赖对应冻结来源；缺失历史快照明确报错，不回填当前题库。
