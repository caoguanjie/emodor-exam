# 现有新增/修订试题弹窗 Tiptap 集成验收

范围：[融合设计](../docs/superpowers/specs/2026-10-26-manual-question-tiptap-design.md)、[实施计划](../docs/superpowers/plans/2026-10-26-manual-question-tiptap.md)。本记录覆盖此前仅精简原表单的不足；独立于另一会话的题库启停/审核瘦身整体交付。

## 已接入的实现

- `Questions.vue` 的新增与修订弹窗接入 `ManualQuestionEditor`，沿用当前入口/API、版本和启停基线、响应未知锁及未保存保护。弹窗宽 760px，挂载 body，头尾固定、中部滚动。
- 题干和选项复用 Tiptap question 内核，解析复用 rich 内核，提供格式工具栏与受控图片。顶部仅题型、培训类别、难度。重复的“未保存内容预览”已移除。
- 字母设答案、选项增删、拖拽/上移下移都以稳定选项 ID 为准；单选/多选/判断各自保留约束。右侧设答案、正确答案标识与 × 删除按最新截图要求实现。
- 内容以 schema 3 JSON 保存；兼容字段由 JSON 单向投影，不再由打开时的旧快照覆盖用户新编辑的富文本。新建、修订都不提交题库分值、考点或资料来源。
- 保存并新增只在收到有效 `saved_version_id` 且草稿仍对应本次请求时清空正文，保留题型/类别/难度。失败、冲突、未知回包不开始第二题。
- 图片上传通过受控资产 API，使用随文档变动映射的位置锚点，关闭/换题后取消并忽略迟到结果。上传未完成或编辑器存在无法安全转换的内容时不能保存。
