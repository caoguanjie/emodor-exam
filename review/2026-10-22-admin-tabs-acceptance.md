# 管理端公共标签页验收记录

## 范围

- 将管理端访问页签抽成公共 `BusinessTabs` 组件。
- 固定不可关闭的首页，业务页面按访问顺序形成可关闭标签。
- 右侧统一提供刷新、关闭当前、关闭其它、关闭左侧、关闭右侧、关闭所有。
- 页签外观适配参考系统的重叠弧形轮廓、活动页底色与关闭按钮展开方式；右侧使用可旋转的四宫格标记和对应操作图标。
- 公共布局增加可持久化的侧栏展开/收起按钮；当前页面名称位于按钮右侧，收起后一级菜单使用图标在上、文字在下的紧凑布局。
- 沿用 RuleExam 的路由、未保存确认、缓存失效和主题变量；不搬参考项目的 Router 工具链、缓存仓库、配色或列表右上角工具栏。

## 自动化证据

- `cd web && node --test tests/*.test.mjs`：135 项通过，0 失败。
- `cd web && npx vue-tsc --noEmit`：通过。
- `cd web && npm run build`：通过，Vite 生产构建完成。
- 回归用例覆盖固定首页、六项菜单、关闭左侧、关闭右侧、批量关闭时保留不可关闭标签并持久化剩余标签，以及未保存内容取消时原子不变。关闭所有还校验先离开当前页面再使缓存失效，避免待关闭页面被额外挂载并重复请求。

## 浏览器证据

- Chrome 本地管理端验证固定首页、动态业务标签和右侧操作菜单均可见。
- Chrome 视觉复核确认：非活动页关闭按钮默认收起，活动页呈现重叠弧形浅蓝轮廓；四宫格展开时旋转并变为主色，菜单图标与六项操作语义一致。
- Chrome 验证 232px 展开态与 68px 紧凑态；收起后一级菜单图标和文字完整显示，当前项保持高亮，刷新页面后状态保持，顶部页面名称位于切换按钮右侧并与按钮垂直居中。
- 在四个业务标签中验证关闭左侧：保留当前及右侧标签；验证关闭右侧：保留当前及左侧标签。
- 验证关闭当前：当前业务标签移除并回到业务首页。
- 验证关闭所有：业务标签全部移除，固定首页保留并成为当前页。
- 菜单展开时六个操作文字与禁用状态符合当前标签位置。

## 边界

- 浏览器验收使用本地已有登录会话；未覆盖移动端 H5，本期也不要求独立 H5 改造。
