# 学员登录服务协议交互验收

用户要求：协议区增加默认未选复选框，未勾选时点击登录先二次确认；最终统一成一行“□ 我已阅读并同意《服务协议》”，只保留一个链接。协议正文从用户指定的[旧站服务条款](https://edu-test.emodor.com/xyh5/#/pages/center/service)读取，主体改为“海珠区安全教育培训中心”。

## 实现

- `LoginConsent.vue` 复用 Wot UI 2.3.2 的 `wd-checkbox` 和 `wd-dialog`，真实短信登录与静态预览共用。勾选只属于当前页面，不写浏览器持久存储，不改认证 API。
- 未选且表单有效时弹出“请阅读并同意协议”，提示点击“同意并登录”会自动勾选同意《服务协议》并继续。取消或遮罩关闭不勾选、不提交；已选直接提交，请求期间禁止重复登录。
- 验证码过期、手机号/验证码/挑战改变、页面隐藏或卸载使待确认失效；确认后重新检查有效性。页面隐藏会递增导航代次，登录响应迟到时不把正在阅读的协议页跳走，离开后再返回也不恢复旧请求的导航资格。
- 单个服务协议链接独立响应，不触发勾选或登录；静态预览链接携带 scenario，保持无业务 API 调用。
- `terms.vue` 与既有 `serviceTerms` 替换为读取到的七节完整正文：服务内容、用户义务、知识产权、隐私保护、免责声明、协议修改、法律适用。标题、介绍使用当前机构名，保留正文段落编号，移除旧“仅作排版示意”说明。没有新增另一份隐私政策或后端同意留档机制。

## 验证证据

在独立 worktree `.worktrees/mobile-login-consent`、独立 H5 开发服务 `127.0.0.1:5176/mobile/` 验证，没有发送真实短信或提交真实学员登录。浏览器登录 API 使用测试替身；不能表述为真实短信供应商验收。

- 测试先失败于缺少复选框；实现后覆盖未选/已选、取消/遮罩、明确确认后仅一次提交、过期与改手机、静态协议链接与无 API 的预览登录。
- 独立代码审查发现 onUnload 不能覆盖 navigateTo 的 onHide，旧代码在登录响应迟到时会打断协议阅读。浏览器回归先复现该失败，再增加隐藏代次保护；覆盖停在协议页及离开再返回两条路径。
- 最终新增浏览器用例 9/9 通过，包含 320/390 像素宽度单行且不溢出。移动单测初轮 50 文件 493/493 通过；最终候选另做类型检查、登录/静态页面回归与 H5 构建，结果以下方收尾记录为准。
- 根使用 Kimi 在真实 Chrome 的静态预览核对单行复选框、弹框、取消保留未选、服务协议跳转与返回；正文七节齐全、无“知习汇”、无示意占位文案，390 像素无横向溢出。截图保存在 `/tmp/ruleexam-login-consent-single-line.png`、`/tmp/ruleexam-login-service-terms.png` 等临时路径，不入 Git。
