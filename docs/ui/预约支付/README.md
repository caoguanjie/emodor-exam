# 预约支付小程序交互预览

对应设计文件：`../预约支付.pen`。本目录是本地可点击原型，与Pencil画板共用 `screens.json` 的页面内容；不修改或运行产品端业务代码。

## 打开方式

在项目根目录执行：

```sh
./docs/ui/预约支付/start-preview.sh
```

然后打开 <http://127.0.0.1:8766/preview.html>。

- 页面目录提供全部页面与异常状态。
- <http://127.0.0.1:8766/preview.html?embed=1> 适合嵌入画布，手机端也可直接查看。
- 8766已在运行时，直接访问即可；不需要重复启动。
- 通过HTTP读取 `screens.json`，不支持直接双击HTML使用 `file://` 打开。

## 交互范围

1. 手机号／验证码输入与校验、协议勾选、本人资料和实名采集演示。
2. 选择398元或98元，价格与服务摘要同步到确认订单、支付和预约页面。
3. 微信支付弹层仅演示付款；侧栏可以切换付款成功、未付款、待核实等结果。
4. 选择符合套餐的日期和时段，确认预约；改期成功更新安排，失败保留原安排。
5. 主动签到：定位结果、正脸采集及比对演示；没有签到不能新开正式考试。
6. 398元还须本轮现场培训参加确认。此结果只在侧栏模拟工作人员确认，学员业务页面没有自行确认按钮。
7. 正式考试含单选、多选、判断三道可操作示例题、答题卡、主动交卷、按答案评分、再次考试和超时结果。
8. 模拟练习独立演示，不扣正式次数，不要求付费预约签到，但保留登录和实名条件。
9. 个人订单退款申请及审核／人工办理状态；暂停期间阻断预约、改期、签到和新开考。
10. 页面状态保存在当前浏览器会话；点击“重置演示”可重新开始。

## 演示说明

- 顶部持续显示“本地交互原型”，无真实支付、短信、相机、定位、人证比对或退款请求。
- 侧栏“预填演示资料”仅填写虚构示例值，方便走通表单。
- 日期示例采用2026年11月。正常购买日期选择只提供将来开放日期；签到面板默认按本人预约当天演示，也可切换为“非预约当天”检查拦截。
- 页面目录属于设计查看工具，直接选择页面会设置相应示例上下文；业务内的按钮跳转则保留真实的本地流程状态。
- 当前演示试卷为三道题，覆盖单选、多选、判断；正式服务的题量和次数应由实际发布配置与订单承诺决定。
- 课程播放按钮与学习进度是原型状态，不播放真实视频、不结算学习时长；不会替代现场培训参加确认。
- 协议与机构地址使用设计说明及占位信息，正式文案由机构提供。

## 文件

- `screens.json`：页面与模块数据，和Pencil画板共用。
- `preview.html`：预览页面壳层。
- `preview.css`：橙红主题、移动端布局与交互状态。
- `renderer.js`：模块渲染、本地路由、表单和业务状态演示。
- `start-preview.sh`：固定使用本机8766端口启动，不安装依赖。
