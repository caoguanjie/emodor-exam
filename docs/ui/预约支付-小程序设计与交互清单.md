## 依据与范围

- 保留现行学员课程、实名、考试、模拟考及错题功能；冲突时优先最新已确认规则。
- 只设计个人学员小程序，含单位代付员工看到的资格和预约。不包含企业联系人或机构PC管理页面。

## 视觉方向

暖橙红的安全教育服务商店：清晰价格、套餐权益与行动按钮，搭配克制的安全防护图形、暖白卡片和深色文字。优先可信、易读与操作明确，不使用虚构销量、倒计时促销或资质背书。

| 用途 | 候选值 | 规则 |
| --- | --- | --- |
| 主按钮／选中 | #C9401D | 配白字对比度4.96:1 |
| 强调装饰 | #F7682B | 不用于小号白字正文，对比度仅3.01:1 |
| 背景 | #FFF9F5 | 暖白背景 |
| 卡片 | #FFFFFF | 保持清晰层级 |
| 主要文字 | #211D1B | 暖背景对比度16.02:1 |
| 辅助文字 | #6B625D | 白底对比度5.95:1 |
| 中文字体 | 画布可用的清晰中文无衬线 | 优先检查现有字体；数字可用更鲜明的价格字重 |

以上为候选设计值；打开画布后映射到现有变量，避免产生第二套重复组件。使用390×844手机画板，检查375px窄屏；预留微信胶囊、状态栏、底部安全区。正文原则上14–16px，按钮高度至少48px，相邻操作间距至少8px。

## 跨页面弹窗与反馈

1. 登录协议未选、手机号/验证码错误、发送失败、验证码倒计时、会话过期返回。
2. 网络错误、列表加载、空态、重新加载、无服务资格、实名未完成。
3. 下单前报价或权益变化重新确认；用户取消微信支付与付款结果未知分开。
4. 日期无余量、场次关闭、预约保存失败；不产生预约或占位。
5. 改期确认、改期失败；保留原预约、原名额及签到适用关系。
6. 定位授权说明、相机授权说明、超出范围、人证不符、供应商异常。
7. 未签到点击考试的“去签到”弹窗；398元未培训的等待确认提示。
8. 考试须知版本变化、开考检查失败、答题草稿恢复、断网重连、交卷确认。
9. 退款确认、不可退款原因、重复申请提示、审核拒绝及人工办理进度。
10. 退出登录确认、复制订单号成功、联系方式等低风险操作反馈。

## 原型交互约定

- 主要卡片、Tab、主按钮、返回键、筛选、日期与时段选择均应有可验证响应。
- 点击反馈约100ms，页面过渡约220ms，底部弹层约260ms；时长是设计建议，需结合画布原型能力实现。
- 不依赖悬停交互；选中、禁用、加载和错误状态可辨认；提交中避免重复操作。
- 首次购买与改期共享日期选择组件；套餐与培训状态决定可选日期，不让用户自行挑错场次。
- 正式考试未签到先引导签到，398元还需现场培训确认；签到本身不自动开始考试。
- 微信收银台、短信、身份核验、定位和退款均以设计演示状态表示，不发起真实支付、身份上传或外部调用。
- 需先确认Pencil实际支持的原型能力，不能将连线说明或静态状态画板称为已经可点击的交互原型。
