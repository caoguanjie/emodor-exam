# 公共随机考试人工验收用例

**测试日期：** ________　**测试人员：** ________<br>
**测试地址：** ________　**设备／浏览器：** ________

记录方式：每项填写“通过／失败／未测”；失败请附截图和操作步骤。

## 一、测试准备

由开发或管理员确认：

- 已执行 **042 数据库迁移**，更新前后端。
- H5 地址可通过手机访问，二维码地址已配置。
- 短信登录、实名认证服务可用。
- 准备两个不同手机号：A 为“本机构人员”，B 为“外来人员”，**两人的工种均不填写**。
- 准备简单、困难两类测试题，均包含单选、多选、判断；每种题型数量充足。
- 测试题使用明显编号，例如“简单-S001”“困难-H001”，方便核对难度和恢复后的题单。

建议在测试环境执行，不使用正式考试数据。验证码、身份证照片不要放入测试反馈。

## 二、创建验收试卷

创建随机卷“人工验收随机卷”，配置如下：

| 参数 | 配置值 |
|---|---|
| 单选题 | 4 道，每题 10 分 |
| 多选题 | 2 道，每题 20 分 |
| 判断题 | 2 道，每题 10 分 |
| 总题数／总分 | 8 道／100 分 |
| 及格分 | 60 分 |
| 考试时限 | 10 分钟 |
| 每人最多考试次数 | 3 次 |
| 考前学习要求 | 关闭 |

## 三、管理员端用例

| 编号 | 操作步骤 | 预期结果 | 结果 |
|---|---|---|---|
| PC-01 | 新建试卷，选择随机组卷 | 可配置各题型数量、每题分值、总分、时限和次数；默认100道、100分、3次 | |
| PC-02 | 按上述8题配置保存，关闭后重新打开编辑 | 数量、分值、总分、及格分、时限、次数均正确回显 | |
| PC-03 | 将总分改为90分，保持题型合计100分，尝试保存 | 提示分值合计不一致，不能保存无效规则 | |
| PC-04 | 尝试将考试次数设置为0或101 | 输入受限或提示错误，不能保存非法次数 | |
| PC-05 | 恢复正确配置并发布 | 发布成功，学员考试Tab可看到该试卷 | |
| PC-06 | 打开并下载考试入口二维码 | 能预览和下载；二维码指向H5考试Tab，不绑定某份试卷 | |
| PC-07 | 另建测试卷，配置某种难度／题型的抽题数超过可用数量，发布 | 发布失败，提示缺题信息；学员不能参加该失败发布的试卷 | |

## 四、手机入口与身份用例

| 编号 | 操作步骤 | 预期结果 | 结果 |
|---|---|---|---|
| H5-01 | 未登录状态扫描二维码，完成短信登录 | 登录后进入考试Tab，能看到已发布试卷；不自动开考 | |
| H5-02 | 不扫码，直接打开H5，点击考试Tab | 能看到同一份考试，扫码不是参加考试的必要条件 | |
| MP-01 | 直接打开已更新的小程序，点击考试Tab | 能看到同一份考试；本项需单独在小程序验证 | |
| H5-03 | A、B均不填工种，补姓名并完成实名认证 | 工种不阻断资料保存、实名或参加考试 | |
| H5-04 | 未实名时浏览考试列表，选择考试并尝试开始 | 能浏览列表；开考前引导实名；完成后返回所选考试，不自动开考 | |
| H5-05 | 查看列表、登录、实名、阅读考试说明，但不点击开始 | 考试次数不增加 | |

## 五、抽题、答题与恢复用例

A、B分别执行以下用例。

| 编号 | 操作步骤 | 预期结果 | 结果 |
|---|---|---|---|
| EX-01 | A本机构人员开始考试，检查题目编号 | 只抽简单题；共8道，单选4、多选2、判断2，总分100 | |
| EX-02 | B外来人员开始同一份考试 | 只抽困难题；题量、题型分布和总分与配置一致 | |
| EX-03 | 检查本次完整题单 | 同一次考试内没有重复题目 | |
| EX-04 | 回答两题，记录题目和选项顺序，刷新页面 | 恢复同一题单及顺序；同设备本地答案恢复；时间不重置、次数不增加 | |
| EX-05 | 答题中返回考试Tab，再点击继续考试 | 回到原次考试，不重新抽题、不重新计时 | |
| EX-06 | 同一设备、同一浏览器关闭页面后重新进入 | 在截止前可继续原次考试；未清理存储时保留本地草稿 | |
| EX-07 | 按测试题标准答案全部答对并提交 | 得到100分；后台记录与手机结果一致 | |
| EX-08 | 提交成功后刷新结果页、重复进入该记录 | 不重复评分、不新增考试记录，结果保持一致 | |

## 六、重考与次数限制用例

同一账号使用同一份试卷连续完成，**不要新建账号或复制试卷代替重考**。

| 编号 | 操作步骤 | 预期结果 | 结果 |
|---|---|---|---|
| RT-01 | 第一次交卷后，在剩余额度内再次开始 | 创建第二次考试记录，重新抽题；允许与上次部分重题 | |
| RT-02 | 第一次已经及格，再次开始 | 只要次数未用完，仍可重考 | |
| RT-03 | 开始第三次考试，返回Tab再继续 | 显示已用3/3次，但仍能继续正在进行的第三次考试 | |
| RT-04 | 第三次交卷后再次打开考试 | 显示次数已用完，不再提供新开考；可查看本人该卷最近结果 | |
| RT-05 | 用完次数后重新扫码或重新登录 | 次数不重置，仍不能开始第四次考试 | |
| RT-06 | 后台查看该学员的考试记录 | 三次记录都保留，题单、答案和成绩可追溯 | |
| RT-07 | 同一学员进入另一份未参加过的试卷 | 另一份试卷独立计算次数，不受前一份已用次数影响 | |

## 七、超时与发布状态用例

| 编号 | 操作步骤 | 预期结果 | 结果 |
|---|---|---|---|
| ST-01 | 另建1分钟、最多1次的小卷；开始后不交卷，等待到期 | 标记超时未交卷，不自动提交、不评分；该次额度已消耗 | |
| ST-02 | 超时后重新进入上述试卷 | 不能再新开考，可查看超时结果 | |
| ST-03 | 将一份无人正在作答的测试卷撤回，再查看考试列表 | 不再允许开始该卷的新考试；其他考试正常 | |
| ST-04 | 重新发布或新增另一份试卷，再扫原来的通用二维码 | 原二维码仍打开考试Tab，可看到当前可参加考试，无须换码 | |

## 八、100题规模验收

小卷通过后，再创建一份 **100道、100分** 的随机卷。建议单选60道、多选20道、判断20道，各1分。

| 编号 | 操作步骤 | 预期结果 | 结果 |
|---|---|---|---|
| BIG-01 | A、B分别开始考试，检查答题卡 | 均为100道，题型分布正确；A简单、B困难 | |
| BIG-02 | 切题、使用答题卡跳题、选择答案、刷新恢复 | 页面正常，无明显卡死、缺题或答案错位 | |
| BIG-03 | 完成并提交100题答卷 | 提交成功，成绩、题量和总分正确，后台能查看记录 | |
