## 1. 引言

### 1.1 系统背景

知习汇教育平台培训机构端呈现培训类别、课程、学员、题库、试卷、考试记录与统计等管理界面，并提供账号权限、字典、会话、日志及内容设置入口。以下是模块关系，不是已执行成功的业务闭环：

    管理员登录
        ↓
    培训类别 → 课程 → 章节 / 课时（视频上传为静态设计）
        ↓
    学员账号与培训类别
        ↓
    题库（手工录入 / Excel、TXT 文件导入入口）
        ↓
    草稿试卷 → 题库组卷 → 发布 / 撤回入口
        ↓
    答题记录 / 人工批改 / 监控列表（旧站观察；当前项目不交付后两项）
        ↓
    考试统计 → 成绩分析 / 排名

试卷高级设置另有静态组件，但未发现正常打开路径；强制交卷点击设计仅提示暂未开放。两者不作为已经可用的业务环节。

    管理员 → 角色 → 菜单权限树
    部分页面 → 权限标识判断 → 按钮显隐（配置来源、接口授权待确认）
    字典 / 在线用户 / 日志 / 消息 / 网站设置 / 图片设置样例 / 布局设置

### 1.2 文档目标

1. 准确盘点已发现的 27 个后台内容页面及登录、404、根入口，覆盖页面、字段、动作和状态前提。
2. 记录培训类别、课程、学员、题库、试卷和统计的页面需求，区分控件可见与动作执行成功。
3. 明确隐藏页面、不可达组件、示例上传控件和占位按钮，不由名称推定实际能力。
4. 保留原有需求编号；新增遗漏功能，修正错误描述，将安全、数据保护、性能等增强要求单列为 L3 产品建议。
5. 当前项目实现、数据库/API 设计、上线安排与原站数据迁移均不在本次修订范围。

### 1.3 范围与证据约定

本册包括后台认证与公共框架，学习管理、考试管理、统计分析、系统设置，以及隐藏的消息、图片样例、网站设置、另一套统计和布局设置。学员端完整交互不在范围；`#/exam` 没有注册路由依据，不列为学员作答页。

| 等级 / 标记 | 含义 |
|---|---|
| L1 | 2026-10-20 真实浏览器可见的路由、字段、按钮、列表或已执行的非写入交互 |
| L2 | 部署网站公开前端资源中的渲染、条件、事件和请求设计；不代表后台处理成功 |
| L3 | 产品化或重构建议，未确认为原站现有功能，也不代表本次已授权实现 |
| 待确认 | 受账号、状态、数据、上下文或接口影响，现有证据不足 |

第 5 节每条 FR 的现状证据只说明页面或静态设计依据，末列单独记录未验证规则及产品建议。字段必填、前端校验、后台约束分别判断。L1/L2 均不代表保存、发布、导入、评分、上传或权限链路验收通过。

### 1.4 建议优先级

| 优先级 | 含义 |
|---|---|
| P0 | 核心功能的建议优先级，不是原站已实现或新项目已立项的证明 |
| P1 | 运营、管理或使用效率相关的建议优先级 |
| P2 | 辅助功能或后续增强的建议优先级 |
| 待定 | 仅有产品建议、不可达设计或缺少能力证据，是否交付需另行确认 |

#### 试卷题目管理的状态差异
已发布试卷的题目管理页只读展示试题类型、题目内容、分数和排序；当前观察到每题 25 分、排序 1～4，不显示题库导入和移除操作。
草稿试卷的题目管理页支持：
- 按试题类型筛选；
- 从题库导入题目；
- 查看已选题数、全选、单题选择和预览；
- 编辑题目分数与排序；
- 移除已选题目；
- 取消或确认导入。
静态校验包含未选择题目的提示，以及排序/分数的校验文案。已发布态的字段禁用与草稿态不同，不能沿用草稿编辑入口；后台是否接受非法值、发布后的实际保护均未验证。候选页跨页保留选择为静态设计；排除参数仅取当前已加载的试卷题目，不能推定全量去重已正确。

以下是列表标签、菜单条件及提交参数的 L1/L2 设计；上下架、保存的实际落库和学员端影响未执行验证。

    草稿（0）   ──上架设计──> 已上架（1）
    已下架（2） ──上架设计──> 已上架（1）
    已上架（1） ──下架设计──> 已下架（2，落库效果待确认）

| 状态 | 已发现操作 | 证据边界 |
|---|---|---|
| 草稿（0）/已下架（2） | 上架、修改、删除、章节管理 | L2，部分动作另受权限；实际执行待确认 |
| 已上架（1） | 下架 | L1 当前菜单 + L2 条件；不显示编辑/删除/章节入口 |
| 非上架态表单保存 | 保存传 0，保存并发布传 1 | L2；编辑已下架课程后的状态、历史关系待验证 |

草稿不可学习、下架后禁止新学习、保留历史及关联删除保护是 L3 目标，不能把按钮条件当学员端或数据库已实现这些规则的证明。

### 7.2 试卷状态与限制

    草稿（列表标签） ──发布动作设计──> 已发布（列表标签）
    已发布 ──撤回动作设计──> 返回状态待运行确认

- 列表按 publishFlag 仅展示草稿、已发布，没有独立已撤回/已下架标签。
- 草稿态有修改/删除、题库导入、分数/排序编辑与移除设计；发布态题目管理不开放同样编辑。
- 行内预览/打印与独立选择导出分别判断，导出受权限，未验证文件内容。
- 发布前检查、撤回后能否新考试、历史记录与版本保护未验证；历史保护为 L3 建议。
- 高级设置组件不可正常打开，期限/次数/结果设置不作为当前已生效规则。

### 7.3 学员账号状态

    正常选项 ⇄ 禁用选项（表单可见，实际鉴权效果待确认）

资料编辑与独立密码修改分开。禁用后不能登录/学习/考试、重置密码吊销会话、删除保留历史等均属于待验证或 L3 安全/数据目标。登录账号可编辑的现状不等于已执行账号变更。

### 7.4 权限关系

    管理员账号 → 角色多选（L1 表单）
    角色 → 菜单权限树（L1，只观察到菜单节点）
    部分页面 → 权限标识判断 → 按钮显隐（L2）
    按钮权限配置来源 / 路由限制 / 接口授权 / 机构隔离 → 待确认

目录、菜单、按钮是菜单表单的类型选项，不等于角色树已展示相应全部节点。菜单类型映射差异见 5.15；不能从显隐直接推定接口鉴权。

## 8. 非功能需求（全部为 L3 产品建议）

本节保留原有产品化目标，不代表原站已实现、已验收或本次已授权实现。是否纳入交付、具体指标和验证方案需另行确认；第 5 节的现状差异不会被这些目标覆盖。

### 8.1 安全

1. 登录必须包含验证码、密码校验和会话过期。
2. 密码不得明文存储或在列表和日志中展示；所有密码输入场景统一使用遮蔽控件。
3. 角色、菜单、按钮和接口必须同时授权。
4. 已开放的删除、上下架、撤回、发布、清空日志、下线、重置密码建议统一确认并审计；若未来启用真正强制交卷，同样纳入。当前强交占位与轮播删除无确认的现状见第 5 节。
5. 富文本题目、课程简介和评语必须做 XSS 清洗。
6. 上传文件必须校验扩展名、MIME、大小和实际文件内容。
7. 账号禁用、重置密码、强制下线后旧令牌应失效。
8. 日志中的密码、验证码、令牌和文件临时地址必须脱敏。

### 8.2 性能

1. 普通列表首次查询建议在 2 秒内返回。
2. 分页查询必须服务端分页，避免一次加载全部学员、题目或日志。
3. 大文件和视频采用异步上传或对象存储直传，页面展示上传进度。
4. 试题导入、学员导入、报表统计和导出采用任务化处理，避免浏览器长时间无响应。
5. 首页指标和图表支持独立加载，单个统计接口失败不影响其他指标卡。

### 8.3 可用性

1. 所有列表提供加载中、空数据、失败、重试四种状态。
2. 表单错误应定位到具体字段。
3. 重要按钮使用明确动词：保存、保存并发布、发布、撤回、下架、删除、强制交卷。
4. 侧栏、标签页和弹窗关闭后不丢失未提交数据，离开编辑页面需提示。
5. 所有时间统一时区和格式；考试时间、平均用时、开放期限明确区分。

### 8.4 兼容性

1. 管理端定位为桌面浏览器。
2. 需验证 Chrome、Edge 和 Safari 最新稳定版本。
3. 上传、富文本编辑器、表格固定列、弹窗和图表需在目标浏览器可用。
4. 移动端后台适配不是当前页面证据，作为后续产品决策。

### 8.5 可维护性

1. 页面路由、菜单配置和权限标识统一来源，避免静态侧栏与后端权限分叉。
2. 课程、试题、试卷、学员和管理员均应有稳定主键、创建时间、更新时间和操作人。
3. 所有状态变更采用显式状态机并记录变更日志。
4. 媒体资源使用统一资源表，禁止在业务表中重复保存不可追踪的临时 URL。
5. 静态资源加载失败不得阻断登录和其他业务页面。
