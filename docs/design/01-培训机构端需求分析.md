# 01 · 需求分析 —— 知习汇培训机构端管理后台

> 本文档是基于 `https://edu-test.emodor.com/adminpc` 的培训机构端后台盘点结果，按现有 [01-需求分析.md](01-需求分析.md) 的结构编写。
>
> 本文档是新增的“培训机构端”需求基线，不覆盖、不改写现有 RuleExam 制度学习考试系统需求。采集日期：2026-10-20。采集账号：后台管理员账号（不在文档中记录密码）。

## 1. 引言

### 1.1 系统背景

“知习汇教育平台”培训机构端用于管理培训类别、课程、章节课时、学员、试题、试卷和考试结果，并提供机构运营所需的管理员、角色、菜单、字典、在线用户、日志及网站内容配置能力。

后台目前呈现的核心业务闭环如下：

    管理员登录
        ↓
    培训类别 → 课程 → 课程章节 / 课时 / 课件视频
        ↓
    学员账号与培训类别
        ↓
    题库（手工录入 / Excel 或 TXT 导入）
        ↓
    试卷组卷 → 考试限制与成绩展示设置 → 发布
        ↓
    考试监控 / 答题记录 / 人工批改
        ↓
    考试统计 / 成绩分析 / 成绩排名

系统同时提供两条管理支撑链：

    管理员 → 角色 → 权限树 → 菜单 / 按钮
    字典、在线用户、操作日志、系统消息、图片与网站配置

### 1.2 系统目标

1. 让培训机构可以按业务类别组织课程，并维护课程封面、简介、推荐和排序。
2. 让课程内容支持章节、课时、课件和视频等多媒体学习资源。
3. 让学员账号可以批量导入、单个维护、禁用、重置密码，并关联培训类别。
4. 让题库支持单选、判断、多选等题型，既可人工录入，也可通过模板导入。
5. 让管理员按培训类别组建试卷，配置考试时间、开放期限、答卷次数和成绩展示方式后发布。
6. 让机构能够查看考试记录、答题过程、人工批改任务、考试监控和多维成绩统计。
7. 让平台具备可配置的账号权限、菜单、字典、网站内容、媒体资源、在线会话和操作日志能力。

### 1.3 文档范围与读者

**本次范围**：

- 后台登录、首页、侧栏、标签页和账号下拉；
- 学习管理：培训类别、课程、课程章节、课时、学员；
- 考试管理：试题、试题导入、试卷、组卷、试卷发布、答题记录、人工批改、考试监控；
- 统计分析：首页指标与考试统计、成绩分析、成绩排名；
- 系统设置：管理员、角色、菜单、字典、字典值、在线用户、操作日志；
- 隐藏但可直达的内容配置：系统消息、图片设置、网站设置。

**不在本册范围**：

- 学员端完整页面交互；
- 后端 API、数据库表结构和部署实现；
- 当前测试环境真实数据的迁移；
- 未在页面或静态资源中找到证据的业务功能。

**证据等级**：

| 等级 | 含义 |
|---|---|
| L1 | 真实浏览器页面可见，包含路由、字段、按钮或列表事实 |
| L2 | 页面静态资源中存在对应模块、操作文案或接口调用线索，页面运行链路未完全验证 |
| L3 | 为重构闭环提出的产品化要求，必须在产品评审时确认，不代表原站已实现 |

### 1.4 优先级定义

| 优先级 | 含义 |
|---|---|
| P0 | 培训机构核心闭环必需：首版必须交付 |
| P1 | 运营、风控或管理效率重要：首版建议交付 |
| P2 | 后续增强：当前证据不足或可延后 |

## 2. 用户角色与画像

### 2.1 系统内置管理员 / 当前后台管理员

| 项目 | 描述 |
|---|---|
| 典型身份 | 平台或机构的最高权限管理员 |
| 证据 | 当前登录账号为 `admin`；可见全部一级菜单 |
| 职责 | 维护学习业务、考试业务、机构管理员、角色权限、菜单、字典、网站配置 |
| 核心诉求 | 全局可管理、权限可控、异常可追踪、操作可审计 |
| 关键权限 | 当前测试会话可访问全部已发现页面 |

角色管理静态资源包含“系统内置角色不可操作 / 不可修改”的提示，因此重构时应保留内置角色保护规则。

### 2.2 机构管理员

| 项目 | 描述 |
|---|---|
| 典型身份 | 培训机构日常运营人员 |
| 页面证据 | 管理员新增表单提供“机构管理员”角色；角色权限示例中该角色勾选学习管理、考试管理、统计分析，未勾选系统设置 |
| 职责 | 建立培训类别、课程、学员、题库、试卷并查看成绩 |
| 权限边界 | 由角色权限树决定，不能根据当前测试数据推断为固定规则 |

### 2.3 演示数据管理员

| 项目 | 描述 |
|---|---|
| 典型身份 | 测试、演示或数据准备人员 |
| 页面证据 | 管理员新增表单提供“演示数据管理员”；现有角色备注为“用于菜单数据演示，不默认授予额外权限” |
| 职责 | 由平台管理员按需授予菜单权限 |
| 默认权限 | 当前测试数据中四个一级权限均未勾选 |

### 2.4 学员

| 项目 | 描述 |
|---|---|
| 典型身份 | 接受培训、参加考试的人员 |
| 后台证据 | 学员管理维护姓名、登录账号、性别、年龄、联系电话、培训类别和禁用状态 |
| 业务行为 | 在学员端学习课程、参加考试、查看成绩；本册只定义机构端对其数据的管理 |
| 数据边界 | 机构管理员只能通过授权范围查看和维护学员数据 |

### 2.5 权限维护人员

该角色不是单独的固定账号，而是具备“角色管理、权限设置、菜单管理”的管理员。其职责是把角色与菜单、页面、按钮权限建立映射。

## 5. 功能需求清单

### 5.1 全局认证与后台壳（FR-GLO）

| 编号 | 需求名称 | 描述 | 优先级 | 验收要点 |
|---|---|---|---|---|
| FR-GLO-01 | 管理员登录 | 使用账号、密码和验证码登录后台。 | P0 | 正确凭据登录到 `#/home`；错误验证码提示“验证码输入错误”；失败不进入后台。 |
| FR-GLO-02 | 登录与密码安全 | 验证码支持刷新；登录、修改密码、新增/修改管理员和学员、重置密码等密码字段均使用密码框；登录失败给出统一提示。 | P0 | 验证码变化后旧码失效；密码字段不以普通文本显示；错误信息不泄露账号是否存在。 |
| FR-GLO-03 | 退出登录 | 账号下拉提供“退出”，退出前二次确认。 | P0 | 确认后清理会话并回到登录页；取消不退出。 |
| FR-GLO-04 | 修改密码 | 账号下拉提供修改密码弹窗，账号只读，填写原密码、新密码、确认密码。 | P0 | 三项必填；两次新密码不一致时阻止提交；成功后旧密码不可继续登录。 |
| FR-GLO-05 | 侧栏折叠 | 支持折叠和展开侧栏。 | P1 | 折叠不改变当前路由和页面状态。 |
| FR-GLO-06 | 动态标签页 | 打开页面后进入标签页；标签页支持关闭当前、关闭其它、关闭全部、刷新当前。 | P0 | 关闭后有明确的活动标签；刷新只刷新当前页面。 |
| FR-GLO-07 | 统一分页 | 列表支持 10、20、30、40 条/页、上一页、下一页和页码跳转。 | P0 | 切换页大小后数据和总数口径正确；空列表仍保留分页区域。 |
| FR-GLO-08 | 空态与异常提示 | 列表支持“暂无数据”；网络或接口异常显示“请求失败/系统异常”。 | P0 | 空态不误显示旧数据；异常可重试且不破坏当前页面。 |
| FR-GLO-09 | 统一二次确认 | 删除、下架、上架、发布、撤回、退出、清空日志、强制交卷等高风险操作需确认。 | P0 | 取消不产生写入；确认后显示成功或失败反馈。 |
| FR-GLO-10 | 文件上传反馈 | 上传展示文件类型、大小、云端存储或处理状态。 | P1 | 上传失败能定位原因；处理中不能误认为已保存。 |

### 5.4 课程管理（FR-LRN-COURSE）

路由：`#/course`。

| 编号 | 需求名称 | 描述 | 优先级 | 验收要点 |
|---|---|---|---|---|
| FR-LRN-COURSE-01 | 课程列表 | 展示课程名称、封面、培训类别、状态、创建时间、操作。 | P0 | 支持分页、空态、封面加载失败占位。 |
| FR-LRN-COURSE-02 | 课程查询 | 按培训类别筛选。 | P0 | 下拉使用现有培训类别；筛选后总数和页码重置。 |
| FR-LRN-COURSE-03 | 新增课程 | 填写课程名称、课程封面、培训类别、课程简介、首页推荐、排序。 | P0 | 课程名称、封面、培训类别必填；排序为数字；简介可为空或按产品规则限制长度。 |
| FR-LRN-COURSE-04 | 保存草稿 | 新增课程时提供“保存”。 | P0 | 保存后状态为草稿，不出现在学员可学习课程中。 |
| FR-LRN-COURSE-05 | 保存并发布 | 新增课程时提供“保存并发布”。 | P0 | 保存成功后直接变为已上架；缺少必要内容时阻止发布。 |

| FR-LRN-COURSE-08 | 课程删除 | 删除课程及关联数据前提示风险。 | P0 | 有章节、课时、学习记录或考试关联时必须阻止硬删除或转为归档。 |
| FR-LRN-COURSE-09 | 课程封面 | 上传、预览、移除课程封面。 | P1 | 校验图片类型和大小；移除需确认；上传失败不覆盖旧封面。 |

## 6. 核心用例

### UC-01 管理员登录后台

| 项目 | 内容 |
|---|---|
| 主角色 | 管理员 |
| 前置条件 | 账号存在且未被禁用 |
| 主流程 | 输入账号、密码、验证码 → 点击登录 → 服务端校验 → 进入首页 |
| 异常流程 | 验证码错误提示错误；账号或密码错误提示登录失败；网络异常保留表单 |
| 后置条件 | 创建在线会话，记录登录时间、IP 和设备信息 |

### UC-02 建立并发布课程

1. 新建培训类别。
2. 新建课程，上传封面，填写简介、推荐和排序。
3. 保存草稿。
4. 进入章节管理，新增章节。
5. 在章节下新增课时，上传课件或视频。
6. 等待云端资源完成，获取视频时长。
7. 预览并发布课程。
8. 学员端看到已上架课程。

### UC-03 批量导入学员

1. 下载学员模板。
2. 填写姓名、账号、性别、年龄、培训类别、联系电话等。
3. 上传文件。
4. 系统校验格式、账号唯一性和类别存在性。
5. 返回成功条数、失败条数、行号和原因。
6. 成功数据进入学员列表，失败行可修正后重新导入。

### UC-04 创建试题

1. 选择题型和培训类别。
2. 输入富文本题目。
3. 添加或删除选项。
4. 设置正确答案。
5. 保存。
6. 预览题目。
7. 后续可编辑或删除。

### UC-05 导入试题

1. 下载 Excel 或 TXT 模板。
2. 选择培训类别。
3. 上传试题文件。
4. 系统显示导入中。
5. 返回逐行导入结果。
6. 导入成功的题目出现在题库中，失败题目给出原因。

### UC-06 组卷并发布考试

1. 新建试卷并填写名称、考试时间、培训类别、排序和备注。
2. 配置注意事项、开放期限、答卷次数和成绩展示方式。
3. 从题库筛选题目并加入试卷。
4. 设置每题分数和排序。
5. 预览或导出试卷。
6. 保存草稿。
7. 确认发布。
8. 培训类别对应的学员在有效时间内看到考试。

### UC-07 查看答题记录并人工批改

1. 在答题记录或学员试卷列表按条件查询。
2. 打开学员试卷试题。
3. 逐题查看正确答案、学员答案和未作答状态。
4. 填写得分和评语。
5. 选择是否加入错题本。
6. 提交并算分。
7. 返回试卷列表，成绩和批改状态更新。

### UC-08 监控进行中的考试

1. 从已发布试卷进入考试监控。
2. 查看学员、答题进度、考试时间和设备。
3. 对异常考试选择强制交卷。
4. 系统记录操作人、时间和交卷原因。
5. 交卷后进入评分或待批改流程。

### UC-09 查看考试统计

1. 按考试名称和培训类别筛选。
2. 查看参考人数、平均分和总分。
3. 进入成绩分析。
4. 查看及格/优秀指标和成绩排名。
5. 按用时或得分排序。
6. 返回列表继续查看其他试卷。

### UC-10 配置角色权限

1. 新建或选择角色。
2. 打开权限设置。
3. 展开一级菜单。
4. 勾选页面权限和按钮权限。
5. 确定保存。
6. 用该角色账号重新登录验证侧栏、直达路由和按钮权限。

### UC-11 配置网站内容

1. 打开图片设置或网站设置。
2. 上传 Logo、轮播图或其他资源。
3. 预览、替换或移除资源。
4. 保存。
5. 前台刷新后验证新资源生效。

### UC-12 审计和会话治理

1. 在线用户列表查看当前会话。
2. 对异常账号执行下线。
3. 日志按时间范围查询。
4. 查看操作人、请求、IP、平台类型和详情。
5. 高风险操作可从日志回溯。

## 7. 业务状态与规则

### 7.1 课程状态

    草稿 ──保存并发布/上架──> 已上架
      ↑                         │
      └──────修改 / 下架─────────┘
                                │
                             已下架

- 草稿不可被学员正常学习。
- 已上架课程可被学员端发现。
- 下架不删除历史学习数据。
- 删除必须处理章节、课时、资源和学习记录的引用关系。

### 7.2 试卷状态

    草稿 ──发布──> 已发布 ──撤回──> 草稿/已撤回
      │               │
      ├─修改          ├─考试监控
      ├─组卷          ├─打印/导出
      └─预览          └─成绩统计

- 草稿可修改和组卷。
- 发布前必须满足题目和分数规则。
- 已发布试卷的题目、考试限制和成绩展示设置应按版本或变更规则保护。
- 撤回只影响后续考试，不删除历史考试记录。

### 7.3 学员账号状态

    正常 ──禁用──> 禁用
      ↑              │
      └────启用──────┘

- 禁用账号不得登录、学习或考试。
- 重置密码应吊销旧会话。
- 删除优先采用逻辑删除，保留历史成绩、答题和日志。

### 7.4 权限关系

    管理员账号
        ↓ 绑定一个或多个角色
    角色
        ↓ 勾选权限树
    目录 / 菜单 / 按钮
        ↓
    侧栏可见性 + 路由访问 + 接口授权 + 操作按钮

## 8. 非功能需求

### 8.1 安全

1. 登录必须包含验证码、密码校验和会话过期。
2. 密码不得明文存储或在列表和日志中展示。
3. 角色、菜单、按钮和接口必须同时授权。
4. 删除、下架、撤回、发布、强制交卷、清空日志、下线和重置密码必须二次确认并审计。
5. 富文本题目、课程简介和评语必须做 XSS 清洗。
6. 上传文件必须校验扩展名、MIME、大小和实际文件内容。
7. 账号禁用、重置密码、强制下线后旧令牌应失效。
8. 日志中的密码、验证码、令牌和文件临时地址必须脱敏。

### 8.2 性能

1. 普通列表首次查询建议在 2 秒内返回。
2. 分页查询必须服务端分页，避免一次加载全部学员、题目或日志。
3. 大文件和视频采用异步上传或对象存储直传，页面展示上传进度。
4. 试题导入、学员导入、报表统计和导出采用任务化处理，避免浏览器长时间无响应。
5. 首页指标和图表支持独立加载，单个统计接口失败不影响其他指标卡。

### 8.3 可用性

1. 所有列表提供加载中、空数据、失败、重试四种状态。
2. 表单错误应定位到具体字段。
3. 重要按钮使用明确动词：保存、保存并发布、发布、撤回、下架、删除、强制交卷。
4. 侧栏、标签页和弹窗关闭后不丢失未提交数据，离开编辑页面需提示。
5. 所有时间统一时区和格式；考试时间、平均用时、开放期限明确区分。

### 8.4 兼容性

1. 管理端定位为桌面浏览器。
2. 需验证 Chrome、Edge 和 Safari 最新稳定版本。
3. 上传、富文本编辑器、表格固定列、弹窗和图表需在目标浏览器可用。
4. 移动端后台适配不是当前页面证据，作为后续产品决策。

### 8.5 可维护性

1. 页面路由、菜单配置和权限标识统一来源，避免静态侧栏与后端权限分叉。
2. 课程、试题、试卷、学员和管理员均应有稳定主键、创建时间、更新时间和操作人。
3. 所有状态变更采用显式状态机并记录变更日志。
4. 媒体资源使用统一资源表，禁止在业务表中重复保存不可追踪的临时 URL。
5. 静态资源加载失败不得阻断登录和其他业务页面。

## 10. 运行验证边界与待确认项

### 10.1 已确认

1. 侧栏 4 个一级业务域、14 个侧栏页面，以及 `#/examReportDetail`、`#/dictValue` 两个详情/子页面；“16 个页面”不等同于 16 个侧栏入口。

3. 课程、学员、题目、试卷、统计和系统设置的主要业务对象。
4. 通过静态资源确认的隐藏页面及其主要操作文案。
5. 统一的标签页、分页、空态和异常提示模式。

### 10.2 已发现但未完成运行验证

1. `#/courseSection`、`#/questionHistory`、`#/studentQuestionHistory`、`#/studentPaperHistory`、`#/correctExam`、`#/message`、`#/imageSetting`、`#/webSiteConfig`、`#/examMonitor` 直达后部分接口返回“请求失败/系统异常”。

3. 未使用机构管理员、演示数据管理员和学员账号做权限对照，当前角色矩阵中的“按授权”需要后续验证。

9. 题库列表当前存在“按培训类别排序”和“按创建时间排序”按钮，已补充为 `FR-EXM-QST-13`；仍需验证排序方向、分页和筛选联动。

11. 当前角色权限树未看到按钮权限节点；不能把已有菜单树勾选能力当作按钮级授权已实现。
12. 当前观察到的课程均为已上架状态，操作菜单只直接呈现“下架”；课程编辑、删除、重新上架和章节入口需要状态化测试数据复核。
