# 08 · 需求分析 —— 学员移动端 H5（知习汇教育平台）

> **本册定位**：定义知习汇教育平台学员移动端 H5 的页面、交互、学习、考试、成绩、错题和个人中心需求，作为重构项目的产品骨架。术语、数据边界和通用安全规则参考 [01-需求分析.md](01-需求分析.md)，但本册只覆盖学员端，不复制管理端的制度上传、AI 出题、组卷、统计和组织管理功能。
>
> **取证基线**：2026-10-20；目标地址 https://edu-test.emodor.com/xyh5；使用真实 Chrome 页面及约 390×844 的手机视口模拟，未作为真机兼容验收；登录身份为 student 演示账号。样例课程、试卷、成绩和个人资料均来自测试环境，数量和文案不是可写死的产品常量。
>
> **修订记录**：2026-10-21，依据[学员 H5 需求覆盖评审](../../review/h5-requirements-review-2026-10-20.md)补齐功能细节并统一流程。本轮为文档修订，取证日期仍为 2026-10-20，未新增业务写入或真机验收；修订对应关系见 §8.6。
>
> **证据标记**：
>
> - **观察**：在真实 H5 页面上看到并通过点击、快照或截图确认的行为。
> - **静态**：通过当前页面加载的前端资源、路由表或网络响应确认的实现意图；没有等同于完整运行验收。
> - **重构目标**：新项目应达到的产品行为或验收要求，不表示现网已经具备或通过。
> - **待验证**：现有证据不足以确认业务闭环，需要真实题目、测试数据、写入操作或真机补测；业务口径尚未确定的项目另标为“待决”。
>
> 除明确标为“观察”“静态”的现状外，本册功能需求、核心用例、非功能需求和约束均描述重构目标。现网缺陷只记入事实与风险，不作为必须复刻的行为。

## 1. 引言

### 1.1 移动端建设背景

当前 H5 是一个以手机浏览器为主要载体的在线学习平台，采用登录后四底部导航的结构：

- 首页：轮播图、推荐课程和课程入口；
- 课程：课程列表、课程目录、视频课时和学习进度；
- 考试：试卷列表、倒计时答题、答题卡、提交和考试结果；
- 我的：考试记录、错题本、个人资料、修改密码、关于我们、服务条款和退出登录。

页面观察与静态资源共同确认的信息架构如下；标为“静态/待验证”的环节尚未完成运行验收：

    登录
      └─ 首页
          ├─ 推荐课程 → 课程详情 / 课时目录
          ├─ 更多 / 底部课程 → 课程列表 → 课程详情 / 课时目录
          │    └─ 视频学习 / 进度上报 / 完成（静态，播放闭环待验证）
          ├─ 考试中心
          │    └─ 试卷 → 答题 / 答题卡 / 草稿恢复 / 提交前确认
          │         └─ 新交卷或超时处理 → 新结果（静态，闭环待验证）
          │              └─ 查看答案解析
          └─ 我的
               ├─ 考试记录 → 答案解析；已有结果也已单独读取
               ├─ 我的错题本（列表内阅读，不跳入解析页）
               ├─ 个人资料
               ├─ 修改密码
               └─ 关于我们 → 服务条款

平台当前以“课程视频 + 在线试卷”为实际产品形态。它与 01 册中“制度文件 + 在线阅读 + 学习有效性判定”的模型有相似的学习/考试闭环，但课件类型、学习计时方式、考试资格和数据实体并不完全相同，重构时不能直接把两者当成同一实现。

### 1.2 移动端建设目标

1. 在手机宽度下稳定呈现登录页及首页、课程、考试、个人中心四个主导航页面。
2. 课程内容可按章节和课时浏览；有视频的课时支持播放、断点续播、进度上报和完成提示。
3. 考试过程可在移动端完成：单选、多选、判断题操作明确，P1 图片上传题纳入首发范围；题干和选项支持图文，答题卡、倒计时和提交结果可追溯。图片题的真实题目与批改闭环仍需验收。
4. 结果、考试记录和错题本形成复习闭环。
5. 弱网、刷新、误关闭页面时，已保存的学习进度和答题草稿不被无提示地丢弃。
6. 重构时把当前样例中的动态数据、空态、无视频课时、接口异常和会话失效都纳入验收。

### 1.3 文档范围与读者

**本册包含**：

- 学员端页面信息架构、路由、底部导航和页面状态；

## 2. 学员角色与移动端画像

### 2.1 employee / student（普通学员）

| 项目 | 描述 |
|---|---|
| 身份 | 已由平台分配账号的学员；当前演示账号登录后展示姓名“学生演示账号”、工种“产业工人” |
| 目标 | 查看推荐课程，完成视频学习，参加可用试卷，查看考试结果和错题 |
| 数据范围 | 只能查看自己的课程进度、考试记录、答案、错题和个人资料 |
| 可变更数据 | 可修改个人资料、头像和密码；考试提交、视频学习进度会产生业务记录 |
| 不可执行 | 不能进入管理端，不能创建/发布课程或试卷，不能修改题库和他人成绩 |
| 使用场景 | 手机浏览器碎片化学习、移动端答题、弱网或切后台后继续使用 |

### 2.2 典型使用场景

1. 学员首次登录，进入首页查看推荐课程。
2. 学员从推荐课程直接进入详情，或从首页“更多”及底部“课程”进入列表，查看“未学习 / 已完成 X/Y / 已完成”和进度条。
3. 学员打开课程详情，查看默认展开的章节及自动选中的可播放课时；可手动切换课时，再次进入时从服务端断点继续。课时目录播放百分比与列表完成课时数分别展示。
4. 学员进入考试中心，查看试卷时长，逐题作答并通过答题卡跳题。
5. 学员退出答题页或发生刷新后，恢复属于本人当前作答的草稿；选择重新开始只清空本次答题内容，不延长原考试期限。
6. 学员提交试卷或时间到，查看分数、正确率、答对/错题数和答案解析。
7. 学员从“考试记录”或“我的错题本”复习。
8. 学员在个人资料中更新头像、姓名、手机号、工种、性别和生日，或修改密码后重新登录。

### 2.3 设备、网络与浏览器环境

- 本次观察使用约 390×844 的手机视口模拟；四个主导航页包含约 50px 的固定底栏，课程详情、答题、结果等子页面没有四底栏。
- 目标应覆盖 320–430 CSS px 宽度的主流手机，不能出现横向滚动或按钮被底部导航遮挡。
- 当前资源声明了移动视口、可内联播放的视频和中文 H5 页面；重构应验证 iOS Safari、Android Chrome 以及常见微信内置浏览器。
- 课程视频依赖网络；考试倒计时、答题草稿和服务端保存状态不能依赖客户端时钟单独成立。
- 当前演示账号存在并发登录后令牌失效现象：两个浏览会话交替登录时，前一次会话出现接口 200 后续请求 401“会话已过期”。这证明必须处理会话失效，但不能据此断言产品要求只能单点登录。

## 3. 学员移动端权限与信息架构

|---|---|---|---|

| 考试记录 | 无 | 有 | 只读本人历史 |
| 错题本 | 无 | 有 | 只读本人错题 |

### 3.3 页面状态、入口和跳转边界

| 状态 | 页面表现 | 重构验收要求 |
|---|---|---|
| 加载中 | 列表底部或按钮显示加载文案；密码/资料按钮显示提交中 | 防止重复点击；请求结束后恢复可操作状态 |
| 空列表 | 首页静态实现有“暂无推荐课程”；错题本有“暂无错题” | 空态包含原因和可返回入口，不显示空白页面 |
| 已加载但无更多 | 课程显示“没有更多了”；考试记录显示“— 没有更多数据啦 —” | 已经到末页后不重复请求 |
| 课程三态 | 观察：样例均为“未学习”；静态：按完成课时数还可显示“已完成 X/Y”“已完成”，百分比用于进度条 | 列表完成课时数与目录完成标记一致；不能把完成课时比例等同于单课时播放比例 |
| 进行中/待考试/已结束 | 观察：样例均显示“进行中”；静态：组件定义三态，但列表固定传入进行中，其他状态入口未证实 | 重构由服务端状态决定按钮和可进入范围，不能据组件文案宣称现网状态流转已接通 |
| 批改状态 | 观察：已有记录为错误；静态：解析支持正确、错误、待批改及兜底已批改，解析答题卡有正确/错误图例 | 待批改与错误区分，未知状态不冒充正确或错误；统计口径见 §4.8 |
| 无视频课时 | 详情页保留目录，点击课时提示“该课时暂无视频” | 不改变当前选中课时，不产生虚假的学习进度 |
| 会话失效 | 401 时清理会话并回登录，提示原因 | 已保存的服务端学习/考试数据不丢失 |
| 提交确认 | 观察：主动提交前显示未答数量及“继续答题 / 确定提交”；超时分支只有静态证据 | 主动提交需确认；超时不等待用户确认，汇总最新答案并自动提交，服务端确认后才显示成功 |
| 本地草稿 | 观察：恢复或重新开始可操作；静态：现网按试卷 ID 保存答案及最近变更时的计时快照 | 目标按学员、试卷、本次作答和版本隔离；重新开始保留原截止时间，成功交卷后清理 |

## 4. 功能需求清单

以下需求编号只属于本册，保留 FR-H5-01～44 连续编号。验收要点中的“观察”“静态”只说明现站证据；其余条款为重构目标，具体边界见 §4.8，不能据需求条目存在推断现网已经通过验收。

### 4.1 登录与会话（FR-H5-01 ～ FR-H5-06）

| 编号 | 需求名称 | 需求描述 | 优先级 | 验收要点 |
|---|---|---|---|---|
| FR-H5-01 | 学员登录 | 登录页提供账号和密码输入框、登录按钮；当前运行时调用学员登录接口并跳转首页 | P0 | ① 观察：页面文案为“请输入账号”“请输入密码”“登录”；② 账号或密码为空时分别提示“请输入账号/请输入密码”；③ 正确凭据成功后进入首页；④ 登录期间按钮进入 loading，不能重复提交 |
