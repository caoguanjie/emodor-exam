# 培训成绩分析弹窗设计

## 目标

将统计分析列表中的“成绩分析”从独立内页改为内容区弹窗。弹窗聚焦考试概况和成绩排名，不再混入课程完成情况，也不要求当前固定卷选择无业务价值的难度。

## 交互

- 统计考试列表始终保留在弹窗下方；关闭弹窗后保留列表筛选与页码。
- 继续支持 `paper_id` 地址参数：首页等入口可直接打开指定考试的成绩分析弹窗。
- 弹窗挂载到 `contentDialogTarget`，只覆盖后台内容区；宽度 `min(1200px, calc(100vw - 32px))`，头尾固定、正文滚动。
- 打开后立即显示加载状态；关闭或切换考试时终止旧请求，迟到响应不得覆盖当前数据。
- 页面被 `KeepAlive` 缓存但切到其他后台页签时，成绩弹窗和答卷详情必须隐藏并解除滚动锁；返回统计页后按当前地址恢复成绩分析，不丢列表筛选与页码。

## 内容结构

1. 使用 Element Plus `el-descriptions`（4 列、边框）展示：考试名称、培训类别、试卷总分、考试时长、及格分、优秀分、当前应考、参考人数、已交卷人数、参考率、平均分、最高分、最低分、及格人数、及格率、平均用时、优秀人数。
2. 未配置优秀线显示“未设置”，优秀人数显示“—”；无最终成绩的分数指标显示“—”，不显示伪造的 0。
3. 排名区保留来源筛选、成绩/用时排序、分页和导出；列为排名、姓名、性别、来源、成绩、用时、操作。
4. 排名不展示答卷 ID；具备 `exam_records:read` 时显示“查看答卷”并复用现有考试记录详情弹窗，无该权限时不提供无效入口。
5. 当前弹窗不展示课程完成、未完成原因、发布 ID、答卷 ID，也不保留独立的“按难度成绩分析”表。

## 难度与兼容

- 当前固定卷：排名和概况直接聚合当前发布版本、相同冻结评分规则下每人的最高最终成绩，API 不要求 `difficulty`。
- 历史随机卷：不同题池不可直接合榜，弹窗显示“卷面难度”选择；未选择时自动选择第一组已有成绩的难度，排名 API 仍要求明确难度。
- `medium`、`unknown` 等历史值继续只读兼容；数据库字段与冻结事实不删除。
- 排名导出统一命名为“培训考试成绩排名.xlsx”，不再显示冗余的难度列；历史随机卷的已选难度写入口径说明。

## 非目标

- 不修改自动评分、补考、冻结题单、参与率或排名名次算法。
- 不删除统计接口返回的课程数据，当前仅从成绩分析弹窗移出。
- 不改数据库结构。
