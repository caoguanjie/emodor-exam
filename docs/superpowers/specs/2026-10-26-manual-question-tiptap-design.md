# 现有新增/修订试题弹窗的 Tiptap 融合设计

依据：用户 2026-10-26 最新截图（Pencil `t2Stxx`）及明确纠正。用户要求调整当前录题功能，并集成 Tiptap 题干、选项、答案和解析编辑；仅移除字段、继续使用文本框不满足要求。

## 范围纠正

本设计覆盖以下旧范围解释：

- `2026-10-26-question-bank-slimming-design.md` 中“人工录题和修改继续使用 main 现有表单，不接独立试题设计器；完整 Tiptap 仍只服务已经批准的试卷设计器及其安全内容链路”。
- `2026-10-26-question-bank-slimming.md` 中将“沿用 main 表单”理解为继续使用 textarea/普通选项输入框的实施条款。
- 上一轮无分值验收记录中“没有将静态画板中的整套富文本工具栏、拖拽选项或保存并新增复刻进表单”的交付边界。

保留现有列表入口、弹窗位置和新增/修订保存链路。在弹窗内部复用已有 Tiptap 编辑内核；不新增独立题目设计器页面。另一会话的启停状态、权限、版本并发校验以其最新合同衔接，不回退为旧审核逻辑。

## 弹窗与交互

顶部三列为题型、培训类别、难度；难度沿用当前启用字典。没有分值、考点、资料来源和新建考点组，也不暗填题库默认分数。

“题干与选项”使用一个 Tiptap 题目编辑区。工具栏包含加粗、斜体、下划线、列表及受控图片。题干和每项内容直接在编辑器中修改；选项前字母是正确答案开关，正确项同时显示可辨识的答案状态。

- 单选题只允许一个正确项；多选题允许多个，保存仍遵循服务端至少两个正确项的规则。
- 判断题固定“正确/错误”两项，不能自由增删或编辑其标签。
- 支持添加、删除、拖拽排序选项，另有键盘可用的上移/下移方式。选项换位只改变显示顺序，正确答案跟随稳定选项 ID。
- 右侧操作区必须与设计稿一致：未选项在悬停或键盘聚焦时显示“设为答案”；已选项持续显示“✓ 正确答案”；“×”删除在悬停时使用红色反馈。点击右侧设答案与点击字母走同一答案命令，不能只画装饰性状态。每项操作保留可读的无障碍名称；判断题和至少两个选项的约束继续生效。
- 切换到/离开判断题会重建选项，须先确认；题干和解析保留。多选转单选时若有多个答案，先要求保留一个正确项。
- 答案解析使用独立 Tiptap 富文本区。空解析默认折叠，有内容默认展开；手动折叠不清空内容，不因编辑题干等其它字段突然重置。

底栏显示正确答案摘要与“有未保存修改/暂无未保存修改”，不显示分数，不声明自动保存草稿。新增提供“取消、保存并新增、保存”；修订保留当前状态对应的明确保存动作，例如停用题“保存并启用”。保存并新增只有在取得本次成功版本凭据后才清空题干/选项/解析，保留培训类别、题型、难度，开始全新的题目。

弹窗挂载到 body，避免页面动画影响定位。最大高度受视口约束，标题和底栏固定，中间内容滚动；1366×768 下按钮必须始终可见。编辑器本身就是实时可编辑题面，因此删除重复的“未保存内容预览”。

## 数据与保存

沿用现有 `content_schema_version:3 + content_json`，题干、每个选项和解析都保存受控富文本 JSON。编辑器 `checked` 映射为 `answer_option_ids`，不进入学员题面。兼容的 `stem/options/answer/analysis` 从 JSON 单向投影生成，不能把编辑后的 JSON 用旧 HTML 或旧快照覆盖。

已有 schema 2/3 题目可直接打开，schema 3 的文字格式、表格、图片与稳定选项 ID 需保留。旧 HTML 内容按当前受控转换入口适配；不支持或不能安全保留的内容明确报错，不能静默丢失后保存。新增和修订仍由现有接口创建版本，不复制成新题，不改历史版本和已发布快照。

图片沿用现有鉴权上传/读取及 `asset_id` 引用。工具栏插入时固定题干、某一选项或解析中的插入位置；上传期间修改文档需映射位置，原位置删除或切题后迟到回包不得插错题。失败可重试/取消；临时 Blob、URL 和 File 不写入题目 JSON。上传未完成时禁止保存。

保存失败、版本/启停冲突或响应未知时保留输入，沿用当前页面的刷新/回执恢复规则。未保存取消与离页保护继续有效；连续新增清空草稿不能发生在网络失败或无版本凭据时。

## 验收

1. 当前人工录题和修订弹窗中确实存在 Tiptap 的可编辑题干/选项与解析，工具栏可改变内容格式。
2. 点击字母设置答案、增删和排序可用；排序后答案仍指向原选项，判断题保护有效。
3. 新增、修订、保存并新增均通过现有保存链路；schema 3 保存再打开仍保留格式、图片和答案。
4. 没有分值、考点、资料来源及假自动草稿文案；富文本内容中正常出现这些文字不应被过滤。
5. 900/768 高度可用；上传、保存失败与关闭保护不会丢输入。自动化、浏览器和真实 API 证据分别记录。
