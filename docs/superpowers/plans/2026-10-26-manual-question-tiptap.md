# 现有新增试题弹窗接入 Tiptap

**Goal:** 按用户确认的 `t2Stxx` 弹窗稿，替换现有新增/修订试题中的文本输入，实现可用的题干、选项、答案与解析编辑和保存。

**Architecture:** 保留 `/admin/questions` 的弹窗、版本锁、权限和保存接口；复用现有 `Tiptap/index.vue` 的 question/rich 编辑内核。新增人工录题组件，将编辑 JSON 映射到现行 schema 3 内容和稳定选项 ID，不经过 HTML 来回转换。题目编辑不引入分值、考点或资料来源表单。

**Tech Stack:** Vue 3、Element Plus、项目已安装的 Tiptap 3、schema 3 题目内容。

**结果：** [集成验收记录](../../../review/2026-10-26-manual-question-tiptap.md)。前端集成、自动化及浏览器交互已验证；未在开发库保存测试题，真实 API/数据库升级与另一会话整体交付衔接。

**Spec:** [人工录题 Tiptap 融合设计](../specs/2026-10-26-manual-question-tiptap-design.md)。用户最新图与明确纠正优先；原“人工表单不接 Tiptap”的实现解释失效。仍在现有录题弹窗中集成，不新增独立题目设计器页面。

## 行为与分工

- `ManualQuestionEditor.vue`：顶部题型/培训类别/难度，题干+选项同一区域，点击字母设答案；支持增删和排序选项；解析为可折叠 Tiptap。复用现有受控图片上传/读取，不接受外链或临时 blob 入库。
- 内容适配：schema 2/3 和旧题均能打开；原有格式、图片、稳定选项 ID 在修订中保留；排序后正确答案跟随选项 ID。未知或不支持结构显式阻止保存。
- `Questions.vue`：接入新组件，移除冗余“未保存内容预览”，底部答案摘要与未保存状态；新增提供取消、保存并新增、保存，修订提供取消、保存。成功保存后才能清空并继续下一题；失败/版本冲突/未知响应保留输入。
- 弹窗头尾固定、中部滚动；沿用 append-to-body，768 高度可用。没有自动保存草稿承诺。
- 保留原有新增/修订 API 与状态流，不在本任务中改变另一会话的启停/审核瘦身。题库分值 025 迁移也不在本轮重复修改。
