# 题库移除分值与人工录题入口调整

**Goal:** 人工录题、题库列表和预览不再显示或提交题目分值；试题保存不要求默认分数。分值由试卷关联与发布快照决定。

**Architecture:** 复用现有题目版本、受控媒体和表单保存链路。历史题库分数字段改为可空兼容列，新题和修订不写分数，既有行与历史试卷/成绩不重算。作者编辑器中的卷内分值只服务组卷，不能回流成题库默认分。

**Tech Stack:** Vue 3 / Element Plus / NestJS / TypeORM / MySQL / Vitest / Pencil。

**验收记录：** [2026-10-26-question-bank-without-scores.md](../../../review/2026-10-26-question-bank-without-scores.md)。代码与目标画板已验证；025 尚未应用开发/生产库。

**Spec:** 本会话已确认：去掉“新建考点组”；题目新增、编辑、列表、预览、底栏不呈现任何分值；弹窗顶部仅题型、培训类别、难度；底栏为答案摘要和未保存状态；分值统一在组卷时配置。10:40 用户补充：人工录题中考点、资料来源两个字段均移除，选填区只保留答案解析。

## 约束

- 人工录题不展示或选择考点/资料来源；修订不提交不可编辑的旧关联。同类别、同题型修订保留当前关联；改变类别/题型时新版本解除不匹配的旧考点，旧版本保持原值，不删除考点数据或改变其它入口的同考点去重规则。
- 不把分数字段藏起来后仍提交默认分数。
- 历史试卷、发布快照、考试结果的实际分值保持原值。
- 不改既有迁移 checksum；新增可续跑迁移并同步 init、entities、03/04/05 册。
- 不执行开发库重建、生产迁移、提交或推送。
- 当前已有 `docs/ui/gemini.pen` 用户改动，仅用 Pencil 对目标画板局部修改。
