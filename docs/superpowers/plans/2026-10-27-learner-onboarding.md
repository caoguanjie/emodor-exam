# 学员首次资料补全实施计划

执行方式：Astra 并行前后端、独立审查；遵循用户要求，不经过 SDD。

目标：陌生手机号验证码登录后，姓名和培训工种缺一则进入资料页。姓名、培训工种必填，头像选填；保存后进入实名认证。用户已在本轮明确确认该流程。

契约：复用已有短信注册、POST /me/profile、PUT /me/training-category 和实名 API，不加表、不迁移数据。未实名姓名可编辑（去首尾空白后 1—64 字），实名成功以证件核验姓名为准，已实名普通接口不能改名。工种继续独立二次确认后锁定。资料补齐不代表已实名，视频/考试服务端门禁不变。首次引导可返回浏览；再次登录仍按当前资料判断。
