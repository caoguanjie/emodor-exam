# 学员考试列表与考前须知实施计划

用户批准本轮按 Astra 执行，不经过 SDD。前后端并行、独立关闭重开验证、固定候选独立审查；保留主目录其他并行改动。

## 已确认行为

- 白色居中考试标题，去掉 Tab、总场次、副标题和全局考试记录入口。
- 卡片恢复原稿的层次：两行试卷名称、时长、题量、真实总分，信息栏与右侧操作并排，窄屏可换行。普通已发布不挂状态标签，未交卷且未超时才标答题中并突出卡片。
- 普通按钮进入考试须知，继续答题直接恢复原 record；不重建考试、不延长 deadline。
- 列表只返回已发布试卷或本人有效进行中考试；历史撤回/归档无进行中项只在我的记录查看。为衔接并行批准的撤回发布规则，撤回后未超时原次仍保留继续入口，仅显示答题中。
- 须知保留完整名称、时长/题量/总分/及格分、必要的学习要求与3条核心规则；去内部编号和重复文字，补回真实题型构成：按冻结规则显示各题型题量和总分，等分时显示单题分值，非等分不伪造统一单价。正式开始仍由服务端核验并开启计时。
- 答案恢复仅指本人同一浏览器/小程序本机保存的最小草稿，不承诺跨设备或存储被清理后恢复。

## 任务及边界

- [x] 前端 worker：Live/StaticExamCenter、Live/StaticExamInstructions、相应fixture和针对性测试；不改store考试事实或后台API。
- [x] 后端 worker：AttemptService.list分页前可见筛选及summary有效active投影；读deadlineAt并用同一时点判断。保留detail/历史及GET恢复权威；GET列表不自动评分或交卷，不改表。
- [x] tester：独立新页面重开、同record与截止时间、保存答案恢复、仅一次POST start的隔离浏览器回归；现有native/draft单测，不做真机。
- [x] root：同步API/模块文档与冻结契约；检查截图和固定候选审查，完成必要编译和针对性回归后窄范围同步主目录。

验收重点：分页total不会因前端隐藏历史项而失真；过期in_progress不能标答题中；撤回后原次继续可达；120分等真实分值不能写死100；进须知不消耗考试次数；重开恢复不重计时；学习/实名门禁不被样式重构移除。

## 题型与紧凑列表增量

用户批准信息栏与操作并排，并提供精确Meta参数：lucide timer/list-ordered/award，图标13px、文字12px，组内4px、组间14px。独立列表worker、须知worker与后端worker并行；root同步API/模块文档，统一截图及针对性回归。

后端从assignment优先的冻结规则聚合question_types，旧缺失/畸形数据保留null。只投影type/count/score_per_question/total_score，无需题库查询，不暴露题干答案；零题型不显示，同类型混合分值的单题分为null。无数据库变更。
