# 试卷组卷模式入口瘦身 Implementation Plan

> **For agentic workers:** 使用 subagent-driven-development 执行页面改动，根智能体整合文档和验收。

**Goal:** 管理员默认创建固定题单试卷，不再选择固定/随机组卷，不集成自动选题工具。

**Architecture:** 沿用已有固定卷设计器、发布快照及考试链路；只收起 PC 随机创建和模式切换入口。保留后端随机能力及已有记录的读取，不迁移、不删除数据。

**Tech Stack:** Vue 3、Element Plus、Vitest。

**Spec:** 当前对话已批准第 1、2、4 项建议；用户明确排除第 3 项自动选题工具。

## 边界与审查重点

- 不改数据库/API、学员开考、抽题、评分、发布冻结机制，不做代码提交或部署。
- 保留工作区其他修改，尤其试题预览和题库操作的并发修改。
- 新建请求固定 mode=fixed，不携带随机 rules；创建成功仍进入现有设计器。
- 列表删除模式筛选/模式列及固定卷的实现性规则文案，保留类别、状态及常规考试信息。
- 详情不再提供模式切换。已有随机记录不得被保存成固定卷；可继续查看、管理原记录，但不经复制新增随机卷。
- 不新增自动选题入口，不扩大为删除学习门槛、历史页签等其他业务。

- [x] 同步模块设计中的 PC 入口范围，保留后端固定/随机能力说明。
