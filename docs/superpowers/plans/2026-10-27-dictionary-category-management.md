**Tech Stack:** NestJS / TypeORM / MySQL 8，Vue 3 / Element Plus。

## 重点检查

空分类必须持久存在；固定分类元数据可改而业务项不改；同名并发有唯一约束；分类删除/项写入不产生孤立项；请求迟到不覆盖新选择；失败保存保留输入；左侧隐藏 type 但请求继续使用稳定 type。
